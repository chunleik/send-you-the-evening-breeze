# 把晚风寄给你

一段暖心的原创中文像素叙事游戏。约 10 分钟，阅读速度和探索习惯会影响时长。

林安回到河湾镇，替即将退休的邮递员周伯收三封信。面包房、渡口和坡上的花园，记得一些连她自己都忘了的小事。

本作以日常对话、探索和记忆片段讲故事，所有人物、剧情与对白均为原创，没有使用其他游戏的角色、故事、美术或音乐。

## 开始游玩

没有安装依赖或构建步骤。使用任何静态 HTTP 服务器托管 `dist/` 即可：

```sh
python3 -m http.server 8080 --directory dist
```

在浏览器打开 `http://localhost:8080`。也可以直接打开 `dist/index.html`；不同浏览器对本地文件的存档策略可能不同，推荐 HTTP 方式。

## 操作

- 方向键或 WASD：行走
- E、空格或 Enter：交谈 / 继续；文字尚未显示完时，可立即显示整句
- 点击人物或底部地点按钮：自动走过去并交谈
- J：打开记忆手帐
- Esc：打开 / 关闭菜单
- 手机：点击地点，或使用屏幕方向按钮和交谈按钮
- 点击右上角音符开启音乐，默认静音；背景音乐为原创 Web Audio 合成旋律
- 对话选项可直接点击，也可用 Tab 聚焦后按 Enter

没有倒计时、战斗或失败惩罚。烤面包选错了可以重试。三封信完成后，回到邮局进入结局。结局之后还能在镇上散步。

## 保存与隐私

章节完成后自动存档到当前浏览器的 localStorage。关闭页面后从「继续上次的旅途」恢复；中途退出未完成的章节，会从该章开头继续。菜单的「重新开始」需要再次确认。不同设备、不同浏览器及隐私模式之间不共享存档。

游戏没有分析追踪、广告、后端或账户系统，不上传玩家个人数据。浏览器禁止本地存储时，会显示无法保存的提示。

## 部署

- **任意静态托管**：将 `dist/` 的全部内容作为网站根目录
- **GitHub Pages**：将本项目推送到仓库，在仓库 Settings → Pages 中选择相应分支的根目录。根目录 `index.html` 会跳转到 `dist/index.html`，无需构建。是否启用 Pages 由仓库所有者决定
- 所有资源使用相对路径，支持部署到仓库子路径

## 项目结构

```text
index.html             GitHub Pages 根目录入口
dist/index.html        游戏界面
dist/styles.css        桌面和手机响应式布局
dist/story.js          原创中文剧情及分支
dist/game.js           像素世界、互动、存档及声音
dist/assets/title-art.png  原创生成的标题插画
tests/engine-smoke.cjs  无依赖的剧情状态验证
tests/playthrough.py   Playwright 浏览器端到端测试
```

## 检查

```sh
node --check dist/game.js
node --check dist/story.js
node tests/engine-smoke.cjs
```

状态测试覆盖两种植物 × 三种信件结尾共六条组合、五个主线阶段、三个记忆片段、烤炉错误重试、存档与续玩。测试使用最小 DOM/Canvas 模拟，不代表视觉验收。

浏览器端到端脚本需要安装 Playwright 和 Chromium，并先在 4173 端口托管 `dist/`：

```sh
python3 -m http.server 4173 --directory dist
python3 tests/playthrough.py
```

浏览器测试涵盖完整通关、存档/续玩、手帐、音乐开关、重开确认以及 390×844 手机触控和横向溢出检查。当前交付环境的浏览器/网络限制使该脚本未能实际完成运行，因此桌面及手机视觉结果尚未通过真实浏览器验收；未将这些检查标为通过。

## 美术、声音与许可

- 游戏场景、人物和动画：原创 Canvas 像素绘制
- 标题插画：为本作生成并人工检查的原创像素风图像
- 音乐：原创程序合成旋律，无外部音频文件
- 字体：使用设备自带中文字体；没有外部字体请求
- 无第三方运行时依赖
